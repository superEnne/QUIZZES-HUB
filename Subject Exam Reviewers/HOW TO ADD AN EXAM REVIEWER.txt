HOW TO ADD AN EXAM REVIEWER
===========================

1. Put your raw exam notes in the subject's folder here, for example:
     Subject Exam Reviewers/EA/Midterm.txt

2. The content goes into  src/data/exams.js  (not subjects.js).
   Every subject already has three slots: Prelim, Midterm, Finals.
   A slot with no notes and no questions shows "Coming soon" on the site.
   As soon as it has either one, the card becomes "Open Reviewer".

3. Fill in a slot like this:

    {
      "id": "ea_midterm",
      "term": "Midterm",
      "title": "Midterm Exam Reviewer",
      "description": "Modules 4-6: EA frameworks and governance.",
      "timeLimit": 60,                 <- minutes; use null for no timer
      "pointersPdf": "/pointers/EA_Midterm_Pointers.pdf",   <- optional; put the PDF in public/pointers/
      "notes": [                       <- STUDY NOTES tab
        {
          "heading": "What is an Enterprise?",
          "summary": "First paragraph.\n\nSecond paragraph.",
          "points": ["Key point one", "Key point two"],
          "terms": [
            { "term": "Enterprise", "definition": "An organization whose boundary is defined by shared goals, processes and resources." }
          ],
          "code": "System.out.println(\"optional code example\");"
        }
      ],
      "questions": [                   <- MOCK EXAM tab (same format as subjects.js)
        { "id": 1, "question": "...", "options": ["A", "B", "C", "D"], "answer": 2 },
        { "id": 2, "type": "true_false", "question": "...", "options": ["True", "False"], "answer": 0 },
        { "id": 3, "type": "identification", "question": "...", "answer": "API", "altAnswers": ["Application Programming Interface"] },
        { "id": 4, "type": "enumeration", "question": "...", "count": 3, "items": ["a", "b", "c"] }
      ]
    }

   Only "heading" is required in a topic; summary, points, terms and code are optional.
   All 7 question types from the quizzes work in mock exams:
   mc, true_false, identification, enumeration, output_tracing, fill_code, matching.

4. Want a different term (e.g. "Pre-Finals")? Add another slot with that "term" and a
   unique "id". Don't need Prelim? Delete that slot.
