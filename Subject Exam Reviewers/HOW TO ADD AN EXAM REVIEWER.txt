HOW TO ADD AN EXAM REVIEWER
===========================

Each subject page shows, from top to bottom:
  1. Exam Reviewers     - timed mock exams
  2. Reviewer Pointers  - downloadable PDF reviewers
  3. Quizzes
  4. Flash Cards

Everything for sections 1 and 2 lives in  src/data/exams.js.

-- 1. MOCK EXAM ------------------------------------------------------------

Every subject has a Finals slot. A slot with no questions shows "Coming soon".

    {
      "id": "ea_finals",
      "term": "Finals",
      "title": "Finals Exam Reviewer",
      "description": "Chapters 5-8: ...",
      "timeLimit": 120,                <- minutes; use null for no timer
      "questions": [                   <- same format as subjects.js
        { "id": 1, "question": "...", "options": ["A", "B", "C", "D"], "answer": 2, "explanation": "Chapter 5 - ..." },
        { "id": 2, "type": "true_false", "question": "...", "options": ["True", "False"], "answer": 0 },
        { "id": 3, "type": "identification", "question": "...", "answer": "API" }
      ]
    }

All 7 question types work: mc, true_false, identification, enumeration,
output_tracing, fill_code, matching.

-- 2. REVIEWER POINTERS (PDF) -------------------------------------------------

Put the PDF in  public/pointers/  and add an entry under "pointers":

    "ea": [
      {
        "id": "ea_finals_pointers",
        "term": "Finals",
        "title": "Finals Pointers - Chapters 5 to 8",
        "description": "Short description.",
        "file": "/pointers/EA_Finals_Pointers.pdf",
        "pages": 6
      }
    ]

-- SOURCE FILES ---------------------------------------------------------------

Subject Exam Reviewers/<SUBJECT>/source/ keeps the editable sources
(questions.py, pointers.py) and the scripts that build the PDF and the exam JSON.
