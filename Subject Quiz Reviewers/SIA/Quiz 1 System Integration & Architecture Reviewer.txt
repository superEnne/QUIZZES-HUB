PART I: MULTIPLE CHOICE (Items 1 - 40)
Select the best answer from the choices provided.
1. What is the primary goal of system integration?
A) To replace all existing systems with one single application
B) To create a larger, more complex system that performs better and offers more functionality
C) To reduce the number of hardware components in an enterprise
D) To separate databases from network components
* Answer: B
* Explanation: According to Chapter 2, the goal of system integration is to create a unified and cohesive whole that performs better and offers more functionality than the individual systems would on their own.
2. In the IT world, what is a Systems Integrator (SI)?
A) A hardware component used to connect network cables
B) A company that specializes in implementing, planning, coordinating, and maintaining IT systems
C) A software package that acts as a firewall
D) A legacy system database
* Answer: B
* Explanation: Chapter 2 defines a Systems Integrator on broad terms as a company (like Deloitte, IBM, Accenture) that specializes in implementing, planning, and managing IT systems.
3. Which of the following is an example of a Point-to-Point Integration?
A) An Enterprise Service Bus (ESB) connecting 10 systems
B) An e-commerce online store directly notifying an order fulfillment system
C) A common data format translating XML to EDI
D) A system using an integration silo
* Answer: B
* Explanation: Chapter 2 uses the example of an E-commerce Order Processing setup where the online store connects directly to order fulfillment as a classic Point-to-Point Integration.
4. What is a major drawback of Vertical Integration?
A) It is too flexible and changes constantly
B) It requires an Enterprise Service Bus
C) It creates functional "silos" that are rigid and difficult to manage in the long term
D) It involves too many third-party systems
* Answer: C
* Explanation: Chapter 2 notes that while Vertical Integration is simple for limited systems, it is rigid because any new functionality requires building its own separate functional "silo."
5. Star Integration is also commonly referred to as:
A) Spaghetti Integration
B) Lasagna Integration
C) Bus Integration
D) Point-to-Hub Integration
* Answer: A
* Explanation: Chapter 2 states that Star Integration is sometimes referred to as "Spaghetti Integration" because the numerous point-to-point connections resemble messy spaghetti code.
6. If you connect ten systems to each other using Star Integration, how many separate integrations are required?
A) 10
B) 20
C) 45
D) 100
* Answer: C
* Explanation: Chapter 2 provides the specific example that connecting ten systems using the Star integration method requires 45 separate point-to-point integrations.
7. In Horizontal Integration, what is the separate sub-system used as a common interface layer called?
A) Enterprise Application Integration (EAI)
B) Electronic Data Interchange (EDI)
C) Enterprise Service Bus (ESB)
D) Product Information Management (PIM)
* Answer: C
* Explanation: Chapter 2 specifies that in Horizontal Integration, the common interface layer between all sub-systems is very often referred to as an Enterprise Service Bus (ESB).

* Explanation: Chapter 2's bank example explains that with an ESB, upgrading one system (like the mobile app) doesn't require changing other systems since they just talk to the ESB.
