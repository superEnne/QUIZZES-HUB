MODULE 1: INTRODUCTION TO OBJECT-ORIENTED PROGRAMMING
A. Multiple Choice (Definition)

1. What programming approach modularizes code based on a system's processes (e.g., checking in/out books)?
A. Object-Oriented Programming B. Procedural Programming C. Functional Programming D. Modular Programming
Answer: B — The module states the procedural approach was "the de facto approach" where "code is modularized based on a system's processes."

2. In OOP, objects interact with each other by exchanging:
A. Variables B. Messages C. Loops D. Arrays
Answer: B — OOP is described as "objects and object communication via the exchange of messages."

3. The fundamental object-oriented concepts were first introduced through the class construct in which language?
A. Java B. Smalltalk-80 C. Simula D. C++
Answer: C — "The fundamental object-oriented concepts were first introduced via the class construct in the Simula programming language in the 1960s."

4. OOP was widely accepted as a technique with the advent of:
A. Java B. Smalltalk-80 C. C++ D. Python
Answer: B — "the programming technique was only accepted with the advent of Smalltalk-80 more than a decade later."

5. What principle states that a message sender does not know how the receiver satisfies the request?
A. Encapsulation B. Information hiding C. Inheritance D. Polymorphism
Answer: B — Explicitly defined: "information hiding: the sender of a message does not know how a receiver is going to satisfy the request."

6. In the Benjamin-Sean example, Benjamin is the:
A. Receiver B. Sender C. Method D. Class
Answer: B — "Benjamin is thus a message-sending object" (sender), while Sean is the receiver.

7. The accompanying information sent along with a message (e.g., sofa type, delivery date) is called:
A. Attributes B. Parameters/Arguments C. Constructors D. Fields
Answer: B — "This information is known as the parameters of the takeOrder message."

8. A message with no corresponding method for the receiver to respond to is called:
A. Valid message B. Invalid message C. Static message D. Abstract message
Answer: B — "An invalid message... is one that the receiver does not have the capability to respond to."

B. Identification

9. This is the object that receives a message.
Answer: Receiver — Sean is labeled the receiver in the example.

10. This term refers to the operations Sean performs to fulfill Benjamin's request.
Answer: Method — "A method contains a number of operations detailing how Sean is to satisfy the demand."

11. This is the specific message Benjamin sends to Sean to purchase the sofa.
Answer: takeOrder — Named directly in Figure 1/2 of the module.

12. This approach models objects and their interactions in the problem space rather than processes.
Answer: Object-Oriented Programming — Defined in Lesson 1.0.

13. This programming approach's problem solving involves "analysis of...procedural tasks carried out."
Answer: Procedural Programming

37. int a = 13; int v = 7; System.out.println(a/v);
Answer: 1 — Integer division truncates the decimal; 13/7 = 1 (remainder discarded).

38. float b = 13; int w = 7; System.out.println(b/w);
Answer: 1.8571428 — Since one operand is float, the result is widened to floating-point, giving a decimal quotient rather than truncation.

39. int a = 13; int v = 3; System.out.println(a%v);
Answer: 1 — 13 ÷ 3 = 4 remainder 1; % returns the remainder.

40. int f, g; f = 6; g = f++; What are the final values of f and g?
Answer: f = 7, g = 6 — Postfix ++ assigns the original value (6) to g, then increments f to 7.

41. int f, g; f = 6; g = --f; What are the final values of f and g?
Answer: f = 5, g = 5 — Prefix -- decrements f first (to 5), then assigns that new value to g.

42. Counter m = new Counter(); Counter n = new Counter(); System.out.println(m == n);
Answer: false — "m and n are different objects even if they have the same constituents," so == compares references, not content.

43. Given the Counter class with add() and add(int x), what happens when carpark.add(2) is called?
Answer: The overloaded method add(int x) executes (matched by the single int parameter), incrementing number by 2 (number = number + x), rather than the no-argument add() which increments by 1.

public class Calculator{
  private int numA; private int numB; private double ans;
  public Calculator(){ this(4,2); }
  public Calculator(int numA){ this(6.0,3.0); }
  public Calculator(int numA,int numB){ this.ans=numA-numB; }
  public Calculator(double numA, double numB){ this.ans=numA+numB; }
  public double getAns(){ return ans; }
  public double getAns(int n){ if (n==0) return ans+ans; else return ans*ans; }
}

  public void printAns(Calculator c, int n){ System.out.println(c.getAns(n)); }
}
