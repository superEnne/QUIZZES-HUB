################################################################################
PART I - TERMS AND DEFINITIONS (FOR IDENTIFICATION)
################################################################################

--------------------------------------------------------------------------------
A. VB.NET AND THE .NET FRAMEWORK
--------------------------------------------------------------------------------

1. VB.NET
   - An object-oriented computer programming language implemented on the .NET
     Framework.

2. .NET Framework
   - The Microsoft framework that implements VB.NET and provides the libraries
     that VB.NET has full access to.

3. Object
   - Everything in VB.NET; includes all of the primitive types (Short, Integer,
     Long, String, Boolean, etc.) and user-defined types, events, and even
     assemblies. Also defined as an instance with behaviors and attributes.

4. Object (base class)
   - The base class from which all objects in VB.NET inherit.

5. Primitive types
   - The basic built-in data types of VB.NET such as Short, Integer, Long,
     String, and Boolean.

6. Integrated Development Environment (IDE) for VB.Net
   - Visual Studio 2017.


--------------------------------------------------------------------------------
B. WINDOWS APPLICATION, SOLUTIONS, PROJECTS, AND FILES
--------------------------------------------------------------------------------

7. Splash screen
    - A Windows application that has a Windows user interface; it typically
      closes automatically and does not usually contain an Exit button.

8. Windows application
    - An application composed of solutions, projects, and files, and which has
      a Windows user interface.

9. Solution
    - A container that stores the application's projects and files; it can
      contain several projects.

10. Project
    - A container storing associated files.

11. Source file
    - A file containing program instructions (code).

12. Form file
    - A file that contains code associated with a form. The first form's code
      is stored in Form1.vb, the second form's code in Form2.vb, and so on.

13. Form1.vb
    - The file where the first form's code is stored.

14. Form2.vb
    - The file where the second form's code is stored.

15. .sln
    - The file extension in which names of solution files end.

16. .exe
    - The file name extension of an executable file.

17. Executable file
    - A file that can be run outside of the IDE; its file name ends with .exe
      and it is automatically created when starting a Visual Basic application.

18. Resource file
    - The project file that contains imported images.


--------------------------------------------------------------------------------
C. WINDOWS IN THE IDE
--------------------------------------------------------------------------------

19. Start Page Window
    - The window shown on the Microsoft Visual Studio 2017 Professional startup
      screen.

20. Windows Form Designer window
    - The window used to create the graphical user interface (GUI).

21. Solution Explorer window
    - The window that displays the list of projects contained in the current
      solution, and the items contained in each project.

22. Properties window
    - The window that lists an object's properties.

23. Toolbox window (or toolbox)
    - The window that contains the tools for designing the user interface; each
      tool represents a class.

24. Code Editor window
    - The window that provides templates for creating event procedures.

25. Project Designer window
    - The window that specifies the startup form or executable code to be run.

26. Component tray
    - A special area below the form design area in the IDE that stores controls
      not visible in the user interface at run time.

27. Auto Hide (push-pin) button
    - The button clicked on a window (e.g., the Solution Explorer window) to
      minimize the window to a tab.

28. Show All Files button
    - The button in the Solution Explorer window used to display all files of
      the project (Folder View).

29. Application tab
    - The tab in the Project Designer window used to specify the startup form.

30. Task box
    - Lists the tasks associated with the picture box; used to import an image
      into the project.

31. Managing the windows in the IDE
    - To OPEN a window: Click View on the menu bar, click Properties Window; or
      mouseover the Solution Explorer tab if auto-hidden.
    - To CLOSE a window: Use the Close button on the window's title bar.
    - To MINIMIZE a window to a tab: Click the Auto Hide (push-pin) button on
      the Solution Explorer window.


--------------------------------------------------------------------------------
D. PARTS OF THE PROPERTIES WINDOW
--------------------------------------------------------------------------------

32. Object box
    - Contains the name of the selected object.

33. Properties list
    - Helps identify and access properties.

34. Settings box
    - Shows the current values of properties.

35. Description pane
    - The part of the Properties window that displays a description of the
      selected property (e.g., "The text associated with the control.").

36. Categorized button
    - The button in the Properties window that lists the properties by category.

37. Alphabetical button
    - The button clicked to list the properties alphabetically.


--------------------------------------------------------------------------------
E. THE WINDOWS FORM AND ITS PROPERTIES
--------------------------------------------------------------------------------

38. Windows Form object (or Form)
    - The foundation for the user interface in a Windows application; you create
      the UI by adding objects such as buttons and text boxes to it.

39. Title bar
    - The part of the form that contains the default caption, as well as the
      minimize, maximize, and close buttons.

40. Properties
    - Attributes of an object that determine its appearance and behavior.

41. Class definition
    - Specifies the attributes and behaviors.

42. Namespace
    - Code defining a group of classes.

43. Dot member access operator
    - Specifies the hierarchy of namespaces. Example:
      System.Windows.Forms.Form

44. Name property
    - Refers to the object in code. Each object has a unique name, must begin
      with a letter, and contains only letters, numbers, and underscores.

45. Hungarian notation
    - A naming convention in which the first three characters represent the
      object's type and the remaining characters represent the object's purpose.
      Example: frmCalculateTaxes

46. Camel case
    - The style in which a name is written (for camel's hump).
      Example: frmCalculateTaxes

47. Text property
    - Controls the text displayed in the form's title bar; it also appears on
      the application's taskbar button. Its default value is Form1 and it should
      always be changed to a meaningful value.

48. StartPosition property
    - Determines the form's initial position on the screen. A splash screen's
      StartPosition typically appears in the middle of the screen.

49. Font property
    - Determines the type, style, and size of the font used on the form.

50. Font
    - Indicates the general shape of the characters.

51. Point
    - The unit in which font size is measured.

52. Size property
    - Two numbers separated by a comma and a space; the first number represents
      the width in pixels and the second number represents the height in pixels.

53. BackColor property
    - Determines the form's background color.

54. Location property
    - Specifies the location of the control on the form; includes an X value and
      a Y value.

55. FormBorderStyle property
    - Determines the border style of a form.
      * Sizable  - Allows the user to change the form's size by dragging its
                   borders at run time
      * FixedSingle - Fixed, thin border line
      * None     - No border

56. MinimizeBox property
    - Determines whether the Minimize button appears on the form's title bar.

57. MaximizeBox property
    - Determines whether the Maximize button appears on the form's title bar.

58. ControlBox property
    - Determines whether the title bar appears on the form.

59. Asterisk (*)
    - Indicates that the form has been changed since the last time it was saved.

60. Sizing handles
    - The handles dragged to size a form after selecting it. (You may also select
      the object and press and hold the Shift key as you press the desired arrow
      key.)


--------------------------------------------------------------------------------
F. CLASSES, CONTROLS, AND TOOLS
--------------------------------------------------------------------------------

61. Class
    - A pattern from which an object is created.

62. Controls
    - GUI objects that appear on a form; they are instantiated using tools from
      the toolbox.

63. Label tool
    - Used to create a label control.

64. Label control
    - Displays text that cannot be edited at run time. (Provides run-time
      information or descriptive text for a control.)

65. PictureBox tool
    - Creates a picture box control.

66. Picture box control
    - Displays an image on a form.

67. Button tool
    - Used to create a button control.

68. Button control
    - Used to perform an action when clicked. Examples: OK and Cancel buttons.

69. Timer tool
    - Used to create a timer control.

70. Timer control
    - Processes code at regular time intervals; it does not appear on the user
      interface at run time. (It is used to remove the splash screen.)

71. Interval property
    - The timer property specified in milliseconds. (The frequency of Elapsed
      events in milliseconds.)

72. Enabled property
    - Allows the timer to run if set to True.

73. Tick event
    - Occurs each time an interval has elapsed; the condition is that the timer
      must be running (enabled).


--------------------------------------------------------------------------------
G. THE FORMAT MENU
--------------------------------------------------------------------------------

74.  Format menu
     - Provides options to manipulate form controls.

75. Align
     - Aligns selected controls by left, right, top, or bottom borders.

76. Make Same Size
     - Makes the width and/or height of selected controls uniform.

77. Center in Form
     - Centers one or more controls.

78. Reference control
     - The first control selected, whose size or location you want to match.


--------------------------------------------------------------------------------
H. STARTING AND ENDING AN APPLICATION
--------------------------------------------------------------------------------

79. Startup form
     - Displays when the application is first started.

80. Two ways to start an application in the IDE
     - (1) Click Debug on the menu bar and then click Start Debugging
     - (2) Press the F5 key

81. Exiting a Windows application
     - Common means: Exit option on the File menu, and an Exit button.


--------------------------------------------------------------------------------
I. CODE, EVENTS, AND PROCEDURES
--------------------------------------------------------------------------------

82. Event
     - A user action such as double-clicking.

83. Event procedure
     - A set of program instructions that are processed when an event occurs.

84. Class Name list box
     - Lists the names of objects included in the UI.

85. Method Name list box
     - Lists the appropriate events for the selected object.

86. Selecting a control's event in the Code Editor window
     - Select the class name first and then select the method name.

87. Syntax
     - The rules of a programming language.

88. Procedure header
     - The first line in the code template for an event procedure.

89. Procedure footer
     - The last line in the code template for an event procedure.

90. Keyword
     - A word that has a special meaning in a programming language; it is
       color-coded in the IDE.

91. Sub procedure
     - A block of code that performs a specific task.

92. Sub
     - The keyword that starts a sub procedure.

93. Private
     - The keyword that restricts the use of the procedure to the form where it
       appears.

94. End Sub
     - The keyword that indicates the end of a sub procedure.

95. Event sub procedure name
     - Includes the object name and the event name. Example: btnExit_Click

96. Method
     - A predefined procedure that can be called (or invoked) when needed.

97. Me.Close() method
     - Causes the current form to close; if it is the only form in the
       application, the application terminates.

98. IntelliSense feature
     - Provides appropriate selections as pop-up lists. Type the first few
       letters of the choice, then use the arrow keys to select an item in list.

99. Collapsing / expanding code
     - Click the minus box to collapse code; click the plus box to expand code.


--------------------------------------------------------------------------------
J. SAVING, CLOSING, AND OPENING SOLUTIONS
--------------------------------------------------------------------------------

100. Saving a Solution
     - Save the solution at regular intervals, for example, every 10 minutes.
       (To save, click File, then Save All.)

101. Closing the Current Solution
     - All projects and files contained within are closed.
     - Close Solution option vs. Close option: the Close option just closes the
       IDE designer window.

102. Opening an Existing Solution
     - Only one solution can be open at any one time; the currently open
       solution closes before another opens. (To open, click File, then Open
       Project.)

103. Creating an application
     - Use File, New Project.
