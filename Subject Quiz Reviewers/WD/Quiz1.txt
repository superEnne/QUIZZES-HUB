### (The lists most likely to be asked — discrete, named, countable items)

---

**1. The three stages in the evolution of the web** — Web 1.0; Web 2.0; Web 3.0.

**2. Characteristics of Web 1.0 (4)** — Static HTML Pages (Read-only); Limited Interactivity; Centralized Hosting; Text & Images Only.

**3. Characteristics of Web 2.0 (5)** — Dynamic Content (AJAX, JavaScript, PHP); User-Generated Content; Social Networking Platforms; APIs & Interoperability; Mobile Web Adoption.

**4. Characteristics of Web 3.0 (5)** — Blockchain & Decentralization; Enhanced Privacy & Security; Smart Contracts; Tokenization & Digital Ownership (NFTs); AI & Machine Learning Integration.

**5. Types of websites based on goals and technology (6)** — Web Presence (Homepage / Corporate Website); Blog / Online Magazine / Portfolio; E-Commerce Websites; Landing Page / Microsite; Web Platform (Social Media Websites); Web Apps.

**6. Languages for designing and developing on the web (4)** — HTML; CSS; JavaScript; PHP.

**7. The four elements that make up a webpage (4)** — Content (HTML); Structure (HTML); Presentation / Style (CSS); Behavior / Interactivity (JavaScript).

**8. New Trends discussed in the chapter (5)** — Full Stack; Front-End; Back-End; APIs (Application Programming Interfaces); Database.

**9. Back-end languages mentioned (3)** — PHP; Python; Node.js.

**10. Common database types and their examples** — Relational: MySQL, PostgreSQL · NoSQL: MongoDB.

**11. Understanding the HTML in the Basic Page (6)** — HTML Basics; Universal Format; Describing Document Meaning; Separation of Meaning and Layout; Ease of Writing; Free and Open.

**12. Facts about HTML (7)** — HTML stands for Hyper Text Markup Language; HTML is a language for creating web pages; HTML is not a programming language; It is a markup language; A markup language is a set of markup tags; The markup tags describe how text should be displayed; The purpose of HTML is to create static websites.

**13. Main web browsers (4)** — Google Chrome; Mozilla Firefox; Apple Safari; Microsoft Edge.

**14. Other browsers with smaller market share (3)** — Vivaldi; Opera; Brave.

**15. Ways to validate HTML at the W3C validator (3)** — By URI (web address); By file upload; By direct input.

**16. Types of tags (2)** — Paired tags (have opening `< >` and closing `</ >`); Singular tags (do not require closing).

**17. Parts of an HTML element (4)** — Start tag; Tag name; Content; End tag.

**18. Order of the basic HTML document structure (5 tags)** — `<!DOCTYPE html>` → `<html>` → `<head>` … `</head>` → `<body>` … `</body>` → `</html>`.

**19. Where the `<title>` appears (3)** — Browser tab / toolbar; Favorites / bookmarks; Search engine results (SEO).

**20. Tips for writing good titles (3)** — Use descriptive text (not too short); Keep within 50–60 characters; Avoid keyword stuffing (a list of random words).

**21. Elements that can be placed inside the `<head>` (6)** — `<title>` (required); `<style>`; `<base>`; `<link>`; `<meta>`; `<script>`.

**22. Local host servers (7)** — XAMPP; LAMP; LEMP; MAMP; WAMP; AMPSS; EasyPHP.

**23. Modules shown in the XAMPP Control Panel (5)** — Apache; MySQL; FileZilla; Mercury; Tomcat.

**24. Text editors and their platforms (4)** — Aptana Studio 3 (Cross-Platform); Brackets 1.0 (Cross-Platform); Notepad++ (Windows); TextMate (Mac).

**25. IDEs featured in the chapter (3)** — NetBeans; Visual Studio Code; Atom.

**26. Common coding errors (4)** — Missing closing tag (e.g., `<p>` without `</p>`); Misspelled tag or attribute names; Unpaired quotation marks; Wrong file references (in `<link>`, `<img>`, `<a>`).

**27. Ways to run a web page stored on your computer (3)** — Open in browser via File → Open File, or type the full file path; Use File Explorer and double-click the `.html` file; From an IDE/Text Editor (e.g., Aptana, VS Code), click Run / Open in Browser.

## Part III — Output Tracing

1. The word **DIGNOS** appears in **bold**. `<b>` is the start tag, `b` is the tag name, `DIGNOS` is the content, `</b>` is the end tag; together they form one element.

2. a) The tab shows **Tutorial4us Home**. b) The page shows **My first web page**. The title is never printed on the page itself.

3. a) The tab shows **HELLO QUELLOS**. b) The page shows **I LOVE WEB DEV**.

4. **One line** (which wraps only if the window is too narrow). The browser ignores the line breaks in the source code.

5. They collapse into **single spaces** — the browser ignores extra spaces. The output reads as one normal sentence.

6. **Nothing.** Everything inside `<head>` is metadata and is not displayed on the page; the body is empty.

7. Missing closing tag — `</p>` is absent. The browser will still display "Hello World," but the code is invalid and would be flagged by the W3C validator.

8. "Example of body tag" appears **large and bold** as a heading; "This paragraph is written between the body tag" appears in **normal-sized body text** below it.

9. There can only be **one `<body>` element** in an HTML document.

10. `<!DOCTYPE html>` is in the wrong place. It **must appear before `<html>`**, not inside it.

11. **Wrong file reference** — "stlye.css" is a misspelling of "style.css," so the `<link>` points to a file that does not exist.

12. A **singular tag** — it does not require a closing tag.

13. a) **Dreamweaver book** on the tab. b) **Dreamweaver CC 2014** as a large heading on the page. c) **book.css**, the external stylesheet linked in the head.

14. The page displays **TODO write content**; the tab displays **TODO supply a title**.

15. The browser is not told **which HTML version is being used**. Every HTML document must start with `<!DOCTYPE>`.
